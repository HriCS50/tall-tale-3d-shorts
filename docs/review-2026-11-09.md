## Findings fixed

1. **Capture could falsely report success after encoder failure.** FFmpeg
   process errors and exit codes now propagate. A deliberately invalid output
   format was exercised and returned nonzero without printing a success line.
   Browser startup failures now close the server and browser profile.
2. **The laptop could silently render on a software GPU.** Windows launches
   default to `--use-angle=d3d11` and `--force_high_performance_gpu`; the
   unconditional SwiftShader permission was removed. Every 3D capture prints
   its actual WebGL renderer and this laptop profile rejects non-NVIDIA
   renderers unless the explicit software fallback is selected.
3. **Self-test deleted prior work and could overlook upstream errors.** It now
   creates a unique `.selftest-*` directory, preserves earlier outputs, uses
   `pipefail`, checks the build result, and encodes full-quality test clips.
4. **Word alignment could drop captions.** The production audit found four
   zero-duration words and one reversed timestamp after Whisper alignment and
   clipping. `normalize_windows` reserves a small valid slot for each word
   while retaining valid measured timing. Three regression tests cover the
   observed boundary cases and preservation of good timings.
5. **Installation metadata and Windows dependencies were inconsistent.** The
   skill now has the unique name `tall-tale-3d-shorts`, with Codex installation
   instructions. Existing `faceless-shorts` remains untouched. Git Bash and
   capture discover an already-installed WinGet FFmpeg when PATH is stale.
6. **Small validation/packaging gaps.** Project names reject path traversal;
   preview serving checks path-relative containment; generated scratch,
   credentials files, models and audio are excluded; LF rules protect Bash
   scripts on Windows; font notices were added from the bundled metadata and
   upstream licenses. three.js MIT notices remain with every vendor copy.

## Limits

The default Windows GPU guard is intentionally specific to the owner's NVIDIA
laptop. Other Windows GPUs need a different profile. This was a focused local
pipeline review and production test, not an exhaustive security audit. The
