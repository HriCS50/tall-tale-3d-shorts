# v1.0.0 — Codex export, laptop edition

First GitHub release of the pipeline (2026-11-09).

- Complete faceless-shorts engine: scripts (setup/selftest/new_video/
  voice/words/estimate) and all six styles with STYLE.md, style sheets
  and runnable examples. The 3D styles (Deep Dive, Night File, Tall Tale)
  render real three.js in headless Chrome; full quality is the default.
- `AGENTS.md`: Codex-facing instructions — owner's standing rules for
  HTP_Jinie, production workflow summary, and three render profiles
  (A: RTX 3050 laptop, hardware WebGL — the default; B: Linux llvmpipe
  fallback; C: degraded SwiftShader last resort), each gated by a WebGL
  renderer-string probe.
- Golden example (E1): `examples/emu-war/` — "The Army That Lost to
  Emus" (Tall Tale 3D, 63.9 s, 1080x1920, 24 fps), source only.
- Workflow docs: Muse Shorts Creator guidance + HTP_Jinie preflight.
- `docs/deep-dive-upgrade-plan.md`: the planned v2 upgrade for Deep Dive
  3D (capture/chunk/NVENC speed work, SDF cavity AO + tissue materials,
  Human v2 + organ/vessel/set libraries, telemetry QA) — plan only.

Not included (re-downloaded or re-installed by setup): Kokoro and
Whisper models (~0.9 GB), the Python venv, Chrome, Blender, any
credentials or channel connections, and finished MP4 renders.
