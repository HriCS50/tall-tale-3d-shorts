# Golden example — "The Army That Lost to Emus" (Tall Tale 3D)

A real finished production, included as the reference implementation for
new Tall Tale 3D shorts: 63.90 s, 1080x1920, 24 fps, voice `am_michael`
x1.05, 23 shots, music `bounce`. Facts checked against the Australian
War Memorial and the Journal of Australian Studies (see `sources` in
`script.json`). Published on HTP_Jinie as video LD6dU7eWZy8.

Source only: renders and review frames are stripped (the cover PNG is
kept in `renders/`), and `data/narration.wav` / `data/mix.wav` are
regenerated by `scripts/voice.py` + `tools/mix.py`. Note `src/core/emu.js`
— a project-specific kit addition (the emu flock), a good example of how
new components are added to the style kit for one video.

To re-render: run the repo `scripts/setup.sh` once, then from this
folder run voice/words, `node tools/capture.mjs check`, `cues`,
`scripts/py tools/mix.py .`, QA sheet, and the video capture — using the
render profile for your machine from the repo-root `AGENTS.md`.
